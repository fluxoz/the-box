Guide

Raspberry Pi

A Raspberry Pi 3, 4, or 5 makes a great Box — cheap, silent, low-power. A Pi is flashed, not taken over: you build a ready-to-run image and write it to an SD card.

The curl | sh takeover is a PC/x86 thing (it kexecs into the installer, which the Pi can't do). Flashing is how everything installs on a Pi — this is the Pi's normal path, and it's fully supported.

Build the image

With Nix installed, build the image for your model (pi3-image, pi4-image, or pi5-image):

nix build github:fluxoz/the-box#pi5-image

boxd and the Pi's vendor kernel come prebuilt from a binary cache, so this is mostly downloads — a few minutes, not a from-scratch compile. The result is a raw .img under ./result/sd-image/.

Flash it

sudo dd if=./result/sd-image/*.img of=/dev/sdX bs=4M status=progress conv=fsync
Check /dev/sdX. Point it at the SD card, not a system disk — dd overwrites whatever you give it. On macOS use /dev/rdiskN; the Raspberry Pi Imager can also write a custom .img.

Boot & pair

Put the card in the Pi and power on. On first boot it expands the filesystem to fill the card and comes up as a Box on your LAN — box.local:2693. From there it's the same as any Box: pair your browser and go.
