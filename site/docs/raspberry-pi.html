Guide

Raspberry Pi

A Raspberry Pi 3, 4, or 5 makes a great Box: cheap, silent, low-power. A Pi is flashed, not taken over. Download a ready-to-run image and write it to an SD card. No Nix, no build.

The curl | sh takeover is a PC/x86 thing (it kexecs into the installer, which the Pi can't do). Flashing is the Pi's normal path, and it's fully supported.

Download the image

Recommended: build your image in the Configurator. You get the same image everyone else does, with your Wi-Fi, your pairing code and (if you want one) your SSH key written into it as it downloads. Flash it, power the Pi on, and you are done: no screen, no keyboard, no SSH, and nothing to claim over the network, because the Pi already knows it belongs to you.

If you would rather have the plain image and set it up on the machine itself, grab it for your model from the latest release:

ModelImage
Pi 5thebox-pi5.img.xz
Pi 4thebox-pi4.img.xz
Pi 3thebox-pi3.img.xz

Each image has a matching .sha256 next to it on the release, so you can verify the download.

A personalized download is that same published image with one small settings file swapped inside it. Be aware of what that means for checking it: your copy will not match the published checksum, because your Wi-Fi, your key and your pairing code are inside it. If verifying the hash yourself matters more to you than the unattended install, take the plain image from the release and set the Box up on the machine.

Flash it

Easiest: Raspberry Pi Imager, choose Use custom image, pick the file you downloaded, select the SD card, and write. It handles the decompression.

Skip Imager's own customisation screen. If you built your image in the Configurator your settings are already inside it, and anything you add there is a second, separate set of settings.

Or from a terminal:

xz -dc thebox-pi5.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
Check /dev/sdX. Point it at the SD card, not a system disk, because dd overwrites whatever you give it. On macOS use /dev/rdiskN.

Boot & pair

Put the card in the Pi and power on. On first boot it expands the filesystem to fill the card and comes up as a Box on your LAN at box.local:2693. If you built the image in the Configurator, open the claim link from your recovery kit and it fills your pairing code in for you. Otherwise it is the same as any Box: pair your browser and go.

Build it yourself (advanced)

Prefer to build from source, or want to change the config first? With Nix:

nix build github:fluxoz/the-box#pi5-image

The flake declares the binary caches, so boxd and the Pi's vendor kernel are downloads, not a from-scratch compile. The result is a raw .img under ./result/sd-image/. Flash it the same way.
