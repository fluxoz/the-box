Run a Box

The Box turns a spare computer into a private server you own, and keeps it safe to change. These guides go from a bare machine to a running Box that you, or your agent, manage.

New here? It's two steps: Install, then First steps. That's the whole path from nothing to a paired, running Box, about ten minutes.
